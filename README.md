# Aktien-Check

Aktien-Check (Projekt 2) bewertet eine Aktie mit einem Aktien-Score aus acht Kriterien (je 0–10, gleich gewichtet) und nennt die Rolle, die am besten passt: Satellit, Tenbagger, Compounder oder Dividenden-Aktie. ROIC-Deckel und ROIC-Punkte gelten für den Zweijahres-Schnitt.

Privater, passwortgeschützter Prototyp. Der Inhalt ist clientseitig mit StaticCrypt verschlüsselt. Keine Anlageberatung.

Seite: https://makx164.github.io/Aktien-check/
